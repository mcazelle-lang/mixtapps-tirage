# 🎲 Tirage au sort

Qui commence ? Tire un nom avec suspense, forme des équipes, mélange l’ordre de passage ou lance jusqu’à 3 dés. Un hasard vraiment impartial.

- **Essayer** : https://mixtapps-demos.web.app/tirage/
- **Sur Mixtapps** : https://mixtapps.com/u/ines-moreau/Kqcv7ll0pKC1Gy4VdfMJ (app de démonstration du compte Inès Moreau)
- **Remixer** : sur Mixtapps, « ⚡ Remixer le code » lance l’app dans ton navigateur et un agent IA modifie
  son code ; ton remix est publié sur une branche GitHub à ton nom.

## Lancer en local

Une app statique (HTML, CSS, JavaScript, sans dépendance) : ouvre `index.html`, ou avec Node :

```bash
npm install
npm run dev
```
